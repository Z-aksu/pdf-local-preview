# PDF Local Preview

一个本地 PDF 阅读命令行工具。在任意目录执行 `pdf-view`，它会递归查找该目录及子目录中的 PDF，启动支持局域网访问的 Express 服务，并在 Vue + PDF.js 阅读界面中打开这些文件。

## 环境要求

- Node.js 18 或更高版本
- npm

## 本地安装

在项目目录中执行：

```powershell
npm install
npm run build
npm link
```

完成后，进入任意包含 PDF 的目录：

```powershell
cd D:\path\to\pdf-folder
pdf-view
```

浏览器会自动打开本机的 `http://127.0.0.1:41221`，终端同时会打印 `LAN access: http://192.168.1.20:41221` 这类局域网访问地址。如果该端口已被占用，会依次尝试 `3211`、`3212` 等后续端口。在终端按 `Ctrl+C` 停止服务。

## 命令选项

```text
pdf-view [选项]

-d, --dir <目录>   指定 PDF 所在目录，默认使用执行命令时的当前目录
-p, --port <端口>  指定监听端口，占用时提示并退出；不指定时默认 41221，占用时自动递增
    --host <地址>  指定监听地址，默认 0.0.0.0（支持局域网访问）
    --lan          监听所有网卡，允许局域网设备访问（默认行为）
    --no-open      启动后不自动打开浏览器
-h, --help         显示帮助
-v, --version      显示版本号
```

例如：

```powershell
pdf-view --dir "D:\PDF 资料" --port 4300
pdf-view -d .\documents -p 4300 --no-open
pdf-view --port 4300 --no-open
```

`--dir` / `-d` 支持绝对路径和相对于执行命令时当前目录的相对路径，也支持 `--dir=路径`。路径包含空格时请使用引号。目录不存在或路径不是文件夹时，会在控制台提示并退出。

`--port` / `-p` 支持 0 到 65535 之间的整数，也支持 `--port=4300`；0 表示由系统分配可用端口。显式指定的端口被占用时，会打印占用提示并退出，不会切换端口。不传端口时，仍从 41221 开始，占用时提示并依次尝试后续端口。

## 功能

- 递归展示多级 PDF 文件夹，自动隐藏没有 PDF 的目录
- 文件目录和文档书签支持一键全部展开或全部收起；手动折叠的文件夹层级会按启动目录保存，刷新或重启服务后自动恢复
- 多页签同时打开题目、答案等文档，切换时保留各自的页码、滚动位置、缩放和旋转状态
- 页签栏右侧提供已打开文档下拉列表，支持完整文件名、当前项高亮、同名目录区分、快速切换和独立关闭；不增加页签栏高度
- 没有已保存页签时保持空白阅读区，由用户自行选择要打开的 PDF
- 右击页签可关闭左侧、右侧、其他或全部页签
- 刷新页面后恢复已打开的 PDF 页签及各页签滚动位置，自动忽略已不存在的文件
- 以页内锚点稳定恢复阅读位置，减少重复刷新时由布局重算造成的微小偏移
- 按启动目录记住横屏阅读、专注模式和侧栏收起/宽度状态；不同目录之间不会串用设置
- 收藏常用 PDF 到文件目录顶部的快捷入口，支持在文件行或页签右键菜单中收藏与取消收藏
- 读取 PDF 内置文档目录/书签，点击章节可快速跳转到对应页
- PDF.js 连续滚动阅读与临近页面懒渲染
- 上一页、下一页、页码跳转、缩放、适合宽度、旋转和下载
- 桌面端双栏界面和窄屏抽屉式目录
- 专注模式：按 `Ctrl+Shift+F`（macOS 为 `⌘+Shift+F`）一键隐藏品牌栏、目录、页签和阅读工具栏，只保留 PDF 内容；按 `Esc` 或再次使用快捷键恢复
- 失焦锁屏：点击其他软件、桌面，切换标签页或最小化浏览器后立即遮住阅读内容；返回后点击时间恢复，设置密码时需输入密码，刷新页面仍保持锁定
- 横屏/沉浸式阅读：优先调用浏览器全屏并尝试锁定横屏，不支持时退回网页内最大化显示
- 重新扫描目录，无需重启服务即可发现新文件
- 支持中文、空格及大小写 PDF 扩展名
- 使用 PDF.js 兼容构建，支持缺少 `Promise.withResolvers` 的较旧浏览器

## 失焦锁屏配置

启动服务时会在当前 PDF 根目录下自动创建 `.pdf/config.json`。默认使用执行命令时的目录；指定 `--dir` 时使用该目录。配置示例：

```json
{
  "blurLockScreen": false,
  "lockPassword": "",
  "language": "en"
}
```

`blurLockScreen` 默认是 `false`，失焦锁屏默认关闭，需要时手动改为 `true`。`lockPassword` 初始化为空字符串，不会自动生成密码；启用锁屏且密码留空时，点击页面上的时间数字即可恢复阅读。只包含空格的密码也按未设置处理。

需要密码保护时，在配置中手动填写，例如 `"lockPassword": "0042"`。已有密码会保留，包含前导零的密码需用字符串保存。设置密码后，启动日志会打印 `解锁密码：0042`；未设置时不打印密码行。修改配置后重启服务并刷新页面生效。

已有 `.pdf` 目录和配置文件会复用，只补齐缺失字段，保留自定义字段和密码。配置字段完整时不会重新写入文件；JSON 格式或字段类型错误时会提示文件路径并停止启动，不会覆盖原文件。

锁屏覆盖普通阅读、专注模式和全屏阅读，不会关闭页签或重置阅读位置。点击地址栏或开发者工具也可能因网页失焦而锁屏；仅将鼠标移出网页不会触发。锁定状态按工作区保存在当前标签页的会话中；关闭后重新打开的新会话从正常阅读开始。

遮挡页面沿用阅读器的米色纸张、深绿和朱红配色，只显示时钟、日期和月历，不展示锁定提示。设置密码后，点击时间数字显示输入框，输入密码后点击箭头或按 `Enter` 恢复阅读；也可直接键入密码后按 `Enter`。按 `Esc` 只收起输入框，不会解除保护。

这是用于临时遮挡内容的隐私功能，PDF 接口仍沿用本地服务原有访问方式。配置密码由服务端校验，不会通过配置接口返回浏览器。

## 界面语言配置

在 PDF 根目录下的 `.pdf/config.json` 中设置 `language`，仅支持以下两个值：

- `"en"`：英文，默认值。
- `"zh"`：简体中文。

例如，将上面配置中的 `"language": "en"` 改为 `"language": "zh"`，保存后重启服务并刷新页面即可切换到中文。页面不提供语言设置，语言不会保存到浏览器，也不会跟随浏览器语言自动切换。菜单、按钮、提示、辅助标签、锁屏日期和月历都会使用配置的语言。

新建配置和缺少 `language` 的旧配置会自动补入 `"language": "en"`，原有密码、锁屏开关及额外字段保留。启动时控制台会打印当前语言及可配置的 `en (English)`、`zh (中文)`。

如果设置了其他值（如 `"fr"`、`"zh-CN"`、空字符串或非字符串），服务会停止启动，在控制台打印配置文件路径、无效值及可选语言，不会覆盖配置文件。

## 安全边界

- 默认监听 `0.0.0.0`，支持局域网设备访问；只在本机使用时请指定 `--host 127.0.0.1`
- PDF 接口只允许访问启动目录以内的 `.pdf` 文件
- 跳过符号链接、隐藏目录、`.git` 和 `node_modules`
- 不上传文件，所有读取与渲染都在本机完成

默认监听 `0.0.0.0`，服务会对局域网开放，请只在可信网络中使用。如果只需要本机访问，请显式使用 `--host 127.0.0.1`。

也可以使用显式的局域网启动命令：

```powershell
npm run build
npm run start:lan -- --no-open
```

启动后终端会打印本机可用的局域网地址，例如 `LAN access: http://192.168.1.20:41221`。开发模式下使用 `npm run dev:lan`，或执行 `npm run dev -- --host 0.0.0.0`。

## 开发

启动 Express 服务（需要已有 `dist`）：

```powershell
npm run build
npm start -- --no-open
```

开发 Vue 界面时，可在另一个终端运行 Vite：

```powershell
npm run dev
```

Vite 会把 `/api` 请求代理到 `127.0.0.1:41221`。

运行验证（CLI 集成测试需要先生成前端构建文件）：

```powershell
npm run build
npm test
npm pack --dry-run
```

## 卸载全局链接

```powershell
npm unlink --global pdf-local-preview
```

## 已知限制

- 暂不支持输入加密 PDF 的密码
- 当前版本以 Canvas 渲染页面，不提供文字选择、全文搜索或 PDF 原生文字批注功能
- 浏览器地址栏只有在浏览器允许网页进入原生全屏时才能隐藏；iOS 或嵌入式浏览器会使用网页内的沉浸式降级模式，需要用户手动旋转设备
