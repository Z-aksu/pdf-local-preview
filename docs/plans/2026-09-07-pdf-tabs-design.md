# PDF 多页签设计

## 目标

允许用户同时打开题目、答案等多份 PDF，并在页签间快速切换。每个页签保留独立的阅读现场，包括滚动位置、当前页、缩放比例和旋转角度。

## 交互

单击目录中的 PDF：未打开时在页签条末尾新增页签，已打开时切换到原页签，不创建重复项。页签支持单独关闭；关闭当前页签后优先激活右侧相邻页签，没有右侧时激活左侧。关闭全部页签后显示原有空状态。

目录重新扫描时，保持仍然存在的页签顺序并刷新文件名称；已经删除的文件自动从页签中移除。首次进入应用仍默认打开目录中的第一份 PDF，以延续现有行为。

## 实现

`App.vue` 管理打开页签和当前路径。每个页签使用稳定的文件路径作为 Vue key，并通过 `v-show` 保持对应 `PdfViewer` 实例挂载。切换页签不会重新加载 PDF，因此组件内的页码、缩放、旋转和 PDF.js 文档状态自然保留。

`PdfViewer` 在隐藏前记录精确的 `scrollTop`，暂停尺寸和可见性观察，取消在途渲染并释放 Canvas 像素缓冲；PDF.js 文档和逻辑阅读状态仍保留。显示后使用固定的滚动目标恢复位置并重新渲染视口附近页面。关闭页签才真正卸载组件并销毁 PDF.js 文档，从而在快速切换与资源回收之间取得平衡。

页签遵循标准键盘操作：左右方向键循环切换，Home/End 跳到首尾，Delete 关闭当前页签。激活或关闭页签后自动把选中项滚入页签条的可视区域并恢复键盘焦点。

## 验证

纯函数测试覆盖去重打开、相邻页签选择和目录刷新清理。生产构建验证 Vue 模板与 PDF.js 打包。浏览器实测覆盖打开题目与答案、分别滚动和缩放、来回切换、关闭页签及窄屏横向滚动。
