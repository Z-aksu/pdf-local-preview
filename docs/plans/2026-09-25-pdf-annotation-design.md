# PDF 本地笔记叠加层设计

> 历史设计：PDF 笔记功能已于 2026-10-28 移除，以下内容仅作设计记录。

## 目标

在现有 PDF.js 连续阅读器上增加一个默认关闭的本地笔记能力：用户从“阅读设置”开启入口后，可以在右下角进入标注模式，选择画笔或橡皮擦、颜色和粗细，在页面上绘制；笔记绑定到当前工作区与 PDF 相对路径，刷新和重新打开后恢复。

## 关键取舍

- 不修改原始 PDF，也不引入服务端接口。笔记使用浏览器 `localStorage` 保存，避免影响现有文件服务和下载能力。
- 标注使用每页透明 Canvas 叠加层，笔迹点位保存为页面宽高的归一化坐标，因此窗口尺寸和缩放变化不会让笔迹漂移。
- 进入标注模式后 PDF 视口 `overflow` 与触控行为锁定；再次点击笔记图标收起工具后恢复滚动，避免移动端绘制与翻页手势冲突。
- 设置开关、笔的颜色/粗细都在顶部“阅读设置”中按工作区隔离且默认关闭；阅读页只保留笔记、画笔、圆形橡皮擦和清除的快捷按钮，当前 PDF 的笔迹使用 PDF 级 key 保存。
- 清除笔记使用应用内确认弹窗，提供明确的取消/清除操作、遮罩和移动端触控尺寸，不再依赖浏览器原生确认框。

## 数据流

`App.vue` 负责工作区级总开关，并把工作区与文件路径生成的 storage key 传给 `PdfViewer`。`PdfViewer` 在挂载、切换页签和 key 变化时读取笔迹；每次完成一条笔划后写回。清除操作需确认，并只删除当前 PDF 的笔迹。

笔划记录包含：页码、工具类型、颜色、粗细和归一化点数组。橡皮擦记录为带圆头、较大直径的 `destination-out` 笔划，光标同步显示圆形擦除范围；重绘或缩放时按原顺序回放，因此不需要修改 PDF Canvas。

## 移动端与兼容性

笔记入口和面板使用至少 44px 的触控目标，并避开安全区。标注期间只允许页面绘制，工具栏仍可操作；关闭标注后现有滚动、缩放、横屏和专注模式路径保持不变。localStorage 不可用或容量不足时静默降级为本次会话绘制，不阻塞 PDF 阅读。

## 验证

- 纯逻辑测试覆盖 storage key 隔离、坏数据过滤、点位归一化和设置回退。
- `npm test` 验证既有阅读器、页签、目录、滚动和布局回归。
- `npm run build` 验证 Vue 模板、CSS 和 PDF.js 生产构建。
