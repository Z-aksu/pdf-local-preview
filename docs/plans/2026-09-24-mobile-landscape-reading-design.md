# 手机横屏沉浸式阅读设计

## 目标

- 在 PDF 工具栏中提供一个清晰的横屏阅读入口。
- 用户点击后优先请求浏览器原生全屏，并在浏览器允许时锁定为横屏。
- 原生全屏或屏幕方向锁定不可用时，退回到网页内的 fixed 沉浸层，并保持 PDF 内容可读。
- 保留现有滚动位置、缩放、旋转、页签和阅读模式状态，不让横屏切换破坏阅读现场。

## 交互与兼容策略

`PdfViewer` 负责横屏阅读生命周期：进入时先适宽，随后请求当前 viewer 元素的 Fullscreen API；成功后尝试 `screen.orientation.lock('landscape')`。iOS/iPadOS 或嵌入式浏览器通常不支持完整的方向锁定，因此直接使用 CSS fixed 模式，用户可以手动旋转设备。退出、按 Esc、浏览器主动退出全屏和组件卸载都会统一清理方向锁定、全屏状态和 body 状态。

现有 App 级阅读模式继续作为持久化的界面状态，用于隐藏应用头部、侧栏和页签。横屏 viewer 自身再通过 fixed 层覆盖整个视口，使工具栏和 PDF 视口都获得最大可用面积。按钮文案和 aria 状态同时反映进入/退出状态。

### 按启动目录隔离状态

服务端在目录树响应中返回由启动目录计算出的稳定 workspace ID（只返回哈希，不暴露绝对路径）。前端将阅读模式、专注模式、侧栏收起/宽度、页签、滚动位置和收藏都写入带 workspace ID 的 localStorage key。同一目录停止服务后再次启动仍能恢复；切换到其他目录时只读取该目录自己的状态，不会因为共用端口或浏览器而串状态。原生浏览器全屏/方向锁定仍遵循浏览器安全策略，刷新后恢复的是网页内沉浸布局，不能强制恢复需要用户手势的原生全屏。

页面刷新、导航或进入浏览器后台触发的全屏退出不会被误记为用户主动退出横屏模式；返回页面后仍按目录状态恢复。

## 样式与性能

横屏层使用 `100vw`、`100dvh` 和安全区 padding，PDF 视口在横屏模式下禁止横向滚动并保留纵向触摸滚动。不会额外复制 PDF 页面或重建文档，只触发一次尺寸同步和临近页面重绘；退出时复用现有观察器和滚动恢复逻辑。
