# PDF 文档目录设计

## 目标

读取 PDF 内置的 Outline/书签树，在左侧文件目录旁提供“文档目录”模式，并支持点击章节跳转到对应页面。

## 数据流

每个 `PdfViewer` 在 PDF.js 文档加载后调用 `getOutline()`。对于字符串命名目标调用 `getDestination()`，再用 `getPageIndex()` 把页面引用转换为从 1 开始的页码。解析后的树通过 `outline-change` 事件发送给 `App.vue`，按文件路径缓存；切换多页签时只展示当前文件的缓存目录。

书签节点保留标题和层级。没有可解析页内目标的节点仍显示但置为不可点击，避免错误跳转；第一版不自动分析正文生成目录，也不把外部链接当作本地页面导航。

## 交互与状态

左侧提供“文件 / 文档目录”切换。文档目录加载中、解析失败、无内置书签均有独立状态。点击可定位节点调用当前 `PdfViewer` 暴露的 `navigateToOutline()`，复用现有平滑滚动和当前页更新逻辑。移动端继续使用抽屉式侧栏。

## 验证

纯函数测试覆盖嵌套目录、命名目标、缺失/损坏目标与计数。真实浏览器使用带书签的 PDF 验证目录展示、层级展开和点击跳页；无书签 PDF 验证空状态。
